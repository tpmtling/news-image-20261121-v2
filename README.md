A classic newspaper front page that sums up Saturday 21 November 2026 in one 1024x1024 image: Russian missiles falling on Poland during Moscow's largest air assault on Ukraine this month leads, with Wall Street's AI-led sell-off into correction, Iranian tankers massing to test a US blockade, Cyclone Akvan fading over Odisha, COP31 missing its deadline, and a magnitude 6.7 quake shaking Peru, plus a five-item briefs strip. The picture is drawn deterministically with Pillow by `render.py` from the hand-picked stories in `news_data.md`; `main.py` (standard library only) copies the finished `news_image.png` to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
